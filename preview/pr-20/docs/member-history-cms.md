# 成员履历编辑

在 Pages CMS 的 Team members 中选择成员。原 Biography、研究兴趣、照片、邮箱和个人链接继续使用原字段。

履历仅有两类可选栏目：Work Experience（工作经历）和 Education（教育经历）。博士后经历填写在工作经历中。研究生无需填写，没有内容的栏目不会显示。

每条经历填写起止月份（例如 `2020.11`、`2025.11`）、英文机构、可选中文机构，以及中英文职位／学位说明。结束月份留空表示“至今”；联合培养、专业等可写入学位说明。中文留空时回退英文。

按希望显示的顺序维护列表，通常最新经历在前。已移入列表的履历不要再重复填写到 Biography。保存时不要删除其他非空字段，不要替换未经本人授权的个人资料。

段晓华老师本轮结构化履历来自[华东师范大学官方教师主页](https://faculty.ecnu.edu.cn/_s49/dxh/main.psp)。博士后与博士阶段的时间按官网原样保留，没有推断或调整重叠时间。
